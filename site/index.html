Trajectory
DPS is per-player overall damage ÷ run duration; deaths are parsed from each report's death events. Data is the top ~1,000 runs per dungeon × key level from Warcraft Logs fight rankings (~200 below +10, where the leaderboards are bottomless) — read it as "what strong runs pull", not a population census. Weeks follow each region's own reset (US Tue · EU Wed · Asia ~Wed, UTC).
